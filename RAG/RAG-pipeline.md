# Proposed RAG Pipeline
1. Initial response : Standard, pre-determined, always same every time. Hello user, welcome to (App name), tell me what problems are you facing. (Optional: Include a list of suggested questions)
2. Depending on the response consult a db that includes a list of symptoms, a brief description of the symptom (incase of esoteric situations), related symptoms (for follow up questions), urgency score (a value that tells how serious a symptom is)
3. The agent keeps track of total urgency score and decides the following:
   1. If the symptoms are extremely serious, immediately generate the report, start the emergency hospital recommendation system.
   2. If the symptoms aren't serious, continue to ask the user followup question, (UI feature: add a multiple choice option)
     End convo by are these all the problems you have? if yes start the generate report tool
4. Generate Report Tool:
- Return a JSON file containing the preliminary report of the user:
  - Personal details of the user : Grabbed from the App, this is never sent to the LLM ever
  - Medical details of the user : Actual reports such as pdf, images are grabbed from the app, never sent to the LLM, however their labels are sent to the LLM for the LLM knows you have a X-ray of your chest and legs, since you have a pain in the chest only the legs X-Ray is bundled. This is for the LLM to decided what to include what not.
  - Preliminary Analysis: List of problems and symptoms presented by the user.
  - Recommended Speciality: What type of doctor should the user should see, (these details will also be in the db, what doctor corresponds to what specialty and areas)
  - Total Urgency score, followed by a breakdown (i.e. what symptoms are responsible for the score and their values)
  - List of bundled documents : i.e. medical history
  - Additional details: Any other details such as pre-existing medical conditions (allergies, diabetes, blood pressure, pacemaker, disabilities), other documents the user poses (that the hospital can ask for), known allergies, 
  - Possible disease (Optional and experimental): AI's prediction of the disease, this value is generated by a separate tool, no need to make this for now
5. Once the report is generated rest of the workflow is handled by backend, agent's work is finished.
